EMV
®
Specifications are technical requirements for designing payment products to work seamlessly and securely everywhere.

EMV 3DS allows seamless authentication of consumers to prevent card-not-present (CNP) fraud and increase the security of e-commerce payments.

®
Contact Chip

Level 3
L3 Test Tool Qualification Process
Step 1
TOOL SUPPLIER
Downloads, completes and submits the L3 Test Tool Supplier registration form to EMVCo.
Step 2
TOOL SUPPLIER
Executes an agreement with EMVCo (via a Docusign link).
Receives a registration number and L3 Qualification Packet.
Step 3
TOOL SUPPLIER
Contacts the L3 QSP and declare the product.
Completes a conformance statement.
Step 4
L3 QSP
Verifies the ICS, tests the product and submits a results report to the L3 Test Tool Supplier.
1 of 4
Step 1
Registration
The L3 Test Tool Supplier shall download, complete and submit a Request for Registration form to EMVCo (using the L3_Secretariat@emvco.com email address). Once EMVCo reviews and accepts the form, the L3 Test Tool Supplier will execute L3 Test Tool Qualification Agreement with EMVCo. Once the contract has been executed, EMVCo will provide the L3 Test Tool Supplier with a L3 Qualification Packet containing their registration number.
Obtain the Registration Form
2 of 4
Step 2
Test Tool Declaration
The L3 Test Tool Supplier shall contact the L3 Test Tool Qualification Service Provider (L3 QSP) and execute bilateral, required agreements and contracts. The L3 Test Tool Supplier shall complete an Implementation Conformance Statement (ICS) document in which it provides detailed information about the L3 Test Tool and supported features. The L3 QSP will validate and submit the ICS to EMVCo for verification.
Obtain details of the EMV recognised  L3 Test Tool Qualification Service Provider for L3 qualification testing
3 of 4
Step 3
Test Tool Validation
Once EMVCo has accepted the ICS, the L3 QSP performs testing. The test results are documented in test reports that the L3 QSP submits to the L3 Test Tool Supplier.
4 of 4
Step 4
Test Tool Qualification
Upon receipt of the test reports from the L3 QSP, the L3 Test Tool Supplier decides if it will submit them to EMVCo for test tool qualification. The L3 Test Tool Supplier shall complete a Request for Qualification form and ask the L3 QSP to send the test reports to EMVCo. EMVCo will grant a Letter of Qualification (LoQ) when a test report demonstrates sufficient conformance with the L3 Test Tool requirements. Applicable fees must be paid before the LoQ is granted.
Obtain the Request for Qualification Form
Prerequisites
There are currently no prerequisites to completing the L3 Test Tool Qualification process.
Fee Structure
For each submission of an L3 Test Tool or component thereof for qualification (either for a new qualification, a renewal or update), specific fees shall be paid to EMVCo, as detailed in L3TG Bulletin 003.
Note: The EMVCo Recognised L3 QSP will have a separate fee structure for testing services.  EMVCo is not responsible for L3 QSP testing fees.
Obtain the L3 Test Tool qualification fees
